# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Custom plugins

- `mrdwarf7/lazyjui.nvim`: opens `jjui` for the current Jujutsu repository with `<leader>jj` or `:LazyJui`.
- `iamcco/markdown-preview.nvim`: previews Markdown with `:MarkdownPreviewToggle`.
- `AntonVanAssche/md-headers.nvim`: navigate headings with `<leader>mh` or `:MDHeaders`.
